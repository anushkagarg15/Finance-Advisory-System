# Finance Management and Advisory System
C++ console based application that allows you to manage finances, compare banks and provides you personalized investment tips

## Features
- Finance Management: Track income, expenses, and savings.
- Bank Comparison: Compare interest rates, loan offers, and services across banks.
- Investment Advisory: Get personalized tips based on your financial profile.
- Reports: Generate summaries of your financial activities

## Tech Stack
- Language: C++
- Platform: Console based
